# מפות מיומנויות

כל מסלול הוא קובץ JSON: רשימת יחידות ורשימת מיומנויות. מיומנות היא דבר אחד שאפשר ללמוד בשיעור אחד ולבדוק בתרגילים קצרים. המפות הן טיוטה לעבודה: מוסיפים, מוחקים ומשנים לפי מה שלומדים מהשימוש.

## שדות של מיומנות

| שדה | משמעות |
|---|---|
| `id` | מזהה קבוע (kebab-case). לא משנים אחרי שיש עליו נתונים. |
| `title` | השם המקובל בתעשייה (באנגלית). |
| `goal` | מה הלומד יודע לעשות אחרי שהוא שולט במיומנות (עברית, משפט אחד). |
| `unit` | היחידה שהמיומנות שייכת לה. |
| `level` | מאיזו רמה מצפים לה בראיון: `junior` / `mid` / `senior` / `staff`. |
| `prereqs` | מיומנויות שכדאי לשלוט בהן קודם. יוצרות גרף בלי מעגלים. |
| `kind` | סוג המיומנות, כמו היום באתר: `concept` / `coding` / `design` / `practical` / `behavioral`. |
| `exercises` | סוגי התרגילים שמתאימים לה (טבלה למטה). |
| `weight` | כמה היא חשובה בראיונות: 3 = נשאלת כמעט תמיד, 1 = יתרון. |
| `excellence` | `true` כשהמיומנות מעבר למעבר ראיון: מה שמבדיל את הטובים ביותר בעבודה. |

## סוגי תרגילים

| קוד | תרגיל | נבדק |
|---|---|---|
| `mcq` | שאלה אמריקאית על הבנה ושיקול דעת | מיד |
| `predict` | "מה הקוד / הבקשה / המערכת יעשו?" | מיד |
| `bug` | מציאת הבאג או הבעיה בקטע קוד, שאילתה או תכנון | מיד |
| `complete` | השלמת שורה חסרה בקוד, שאילתה או קונפיג | מיד (השוואה או הרצה) |
| `order` | סידור שלבים בסדר הנכון | מיד |
| `choose` | בחירה בין שתי חלופות תכנון, עם נימוק קצר | מיד (הבחירה), ברקע (הנימוק) |
| `code` | כתיבת פונקציה שרצה מול בדיקות | מיד (בדיקות), ברקע (ביקורת) |
| `query` | כתיבת שאילתת SQL שרצה מול נתוני דוגמה | מיד |
| `design` | תכנון על הלוח עם רובריקה | ברקע |
| `explain` | "הסבר למראיין" בכמה משפטים | ברקע |
| `story` | סיפור STAR | ברקע |

"ברקע" = ה-AI בודק אחרי שהלומד ממשיך, והציון מגיע מאוחר יותר. אף תרגיל לא עוצר את הסשן.

## בדיקת תקינות

```bash
node scripts/check-skill-maps.mjs
```

בודק שכל ה-`prereqs` קיימים, שאין מעגלים, שכל `unit` מוגדרת ושכל סוג תרגיל מוכר.
